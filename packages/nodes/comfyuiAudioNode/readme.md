# ComfyUI-音频生成

接入本地 ComfyUI 工作流的画布节点，用于**语音合成**与**声音设计**。节点把两条独立的文本通道分别写进工作流，并统一管理输出格式与结果音频。

| 节点上的输入区 | 工作流入参 | 说明 |
|---|---|---|
| **待朗读文本** | `text` | 要合成的正文，如 `The cat?` |
| **语音指令** | `instruction` | 音色、性别、语气、口音等描述，如 `gender: Male. pitch: Low.` |
| **输出格式** | `format` | `SaveAudioAdvanced` 的编码格式：MP3 / FLAC / Opus |
| **音质** | `format.quality` | 格式的二级入参：MP3 为 V0 / 128k / 320k，Opus 为 64k / 96k / 128k / 192k / 320k，FLAC 无此项 |
| **随机种子** | `seed` | 决定韵律的细微变化。默认「每次随机」；切到「固定」并填值即可复现同一条声音（取值 1 ~ 2147483647） |
| **参考音频文本** | `reference_text` | 选填，且仅在画布接入参考音频时出现。留空则由工作流内的 Whisper 自动转录这段音频；转写不准时才手填覆盖 |

## 用法

1. 确保本地 ComfyUI 已在 `127.0.0.1:8188` 运行，且「设置 → 媒体模型」里已安装音频供应商（如 Breeze TTS 2 语音生成 / 语音方向控制）。
2. 在画布「添加节点」中选择「ComfyUI-音频生成」。
3. 填写**待朗读文本**与**语音指令**（语音指令在上），选择模型与输出格式，点击「生成」。
4. 「停止生成」会同时撤销 ComfyUI 上已提交的任务（执行中的中断、排队中的移除），不会让它继续占着显存跑完。

## 输入与输出

- **文本、音频输入**（画布左侧端口）：接入的文本按先后顺序分配到两条通道——**第 1 条并入语音指令，第 2 条及以后并入待朗读文本**；接入的音频作为**参考音频**。节点上会显示一行说明当前接入的文本去了哪条通道。
- **音频输出**（画布右侧端口）：生成结果，可接入下游的音频节点或导出。

两条通道在节点上的排列与分配顺序一致：**语音指令在上、待朗读文本在下**。接入的文本统一以「参考 N」的形式并入对应通道（N 为引用在卡片列表中的位置，与输入框里 `@` 提及的编号一致）。

参考音频只有**复刻音色**的供应商会消费——例如「语音方向控制」工作流会把它上传到 ComfyUI，替换工作流里写死的默认参考音频（`Victor.mp3`）。语音设计类供应商不消费音频，接了会被忽略。

节点通过模型的 `referenceAudio` 能力字段区分：声明了 `referenceAudio: true` 的模型（复刻音色类）才会显示「参考音频文本」输入框并真正把音频送进请求；未声明的模型接了音频时，画布上直接提示「当前模型不使用参考音频，接入的音频会被忽略」，且音频不会随请求发送（省去一次无用的文件读取）。新增音频供应商时，若它消费参考音频，需在 model 上声明这个字段。

参考音频说了什么由工作流里的 `BreezeWhisperTranscribe` 现转（Whisper），不需要手写；节点上填的文本只在填了时覆盖自动结果。首次生成若本地没有 Whisper 模型会自动下载（`whisper-large-v3-turbo` 对应 `openai/whisper-large-v3-turbo`，约 1.6 GB），耗时较长。

**模型下拉只列语音合成（TTS）模型**。音乐生成归「ComfyUI-音乐生成」节点，两个下拉不会重叠。供应商用 `audioCategory` 字段声明归属：`"music"` 归音乐节点，不声明（或 `"speech"`）归本节点——历史音频供应商都是 TTS 工作流，不声明的老供应商不需要改就能继续用。

## 与「音频生成」节点的区别

- 「音频生成」是通用节点，列表来自所有已安装音频供应商（含云端），参数按模型能力展示音色、语速、语种、采样率等。
- 本节点面向本地 ComfyUI 工作流：参数只保留工作流真正接收的**输出格式**，音色与风格交给**语音指令**描述，与画布上工作流的 `instruction` 入参一一对应。

## 说明

- 待朗读文本为空时无法生成；语音指令可留空，此时工作流使用它自带的默认声音描述。
- 输出格式以工作流中的 `SaveAudioAdvanced` 入参为准：它只声明 MP3 / FLAC / Opus，其余格式（WAV、OGG）能通过 ComfyUI 的提交校验却会在执行时报错，因此不暴露在界面上。
- 音质是格式的二级入参，档位与 ComfyUI 的「保存音频（高级）」节点一致；切换格式时自动回到该格式的默认档位（MP3 为 V0、Opus 为 128k），FLAC 无损没有音质选项。
- 种子默认每次随机，节点会保留本次用到的种子值——听到满意的声音后切到「固定」就能复现它。
- 参考音频会上传到 ComfyUI 的 `input` 目录（文件名形如 `toonflow_breeze_ref_<时间戳>.mp3`），每次生成上传一份，不会覆盖已有素材。
