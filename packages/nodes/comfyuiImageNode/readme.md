# ComfyUI-图片生成

接入本地 ComfyUI 工作流的画布节点，同时承担**文生图**与**图生图（参考图编辑）**两种用法。节点识别 ComfyUI 工作流中的四个关键控制点：

- **比例（aspect ratio）**：对应工作流 `ResolutionSelector` 的比例参数。
- **分辨率（megapixels）**：对应工作流 `ResolutionSelector` 的百万像素参数，决定输出分辨率。**按 1024 基数**——1MP 出图 1024×1024、2MP 出 2048×2048、4MP 出 4096×4096（非十进制百万）。
- **提示词（prompt）**：对应工作流正提示词文本编码节点。
- **图像（image）**：节点输出生成的图片；同时提供「图片、文本输入」端口，可接入上游图片。

## 用法

1. 确保本地 ComfyUI 已在 `127.0.0.1:8188` 运行，且「设置 → 媒体模型」里已安装 ComfyUI 图片供应商。
2. 在画布「添加节点」中选择「ComfyUI-图片生成」。
3. 填写提示词，选择模型、比例与分辨率，点击「生成」；需要中止时点击「停止生成」——中止会同时撤销 ComfyUI 上已提交的任务（执行中的中断、排队中的移除），不会让它继续占着显存跑完。
4. 需要图生图时，把上游图片节点（或图片素材）接入「图片、文本输入」端口，接入的图会显示在提示词框上方的缩略图列表里。

## 文生图 / 图生图如何切换

节点**不靠节点类型区分**，而是读所选模型声明的 `mode`：

| 模型声明的 `mode` | 节点行为 |
|---|---|
| `["text"]` | 文生图。接入的图片不会参与生成（供应商工作流里没有图片输入节点）。 |
| `["singleImage"]` / `["multiReference"]` | 图生图。生成前**必须**接入至少一张参考图，否则提示「请先接入参考图片」。 |

`mode` 在「设置 → 媒体模型」的模型编辑弹窗里勾选，可选值：文生图 / 单图参考 / 多图参考。未声明 `mode` 的供应商按文生图处理，不强制接图。接入的参考图会以 base64 随请求提交，由供应商写入工作流中的图片输入节点（如 `LoadImage`）。

## 比例与分辨率

选择能吃参考图的模型时，比例会多出一个「**自适应**」选项（列表最后一项）：

| 比例 | 出图比例 | 提交给供应商的参数 |
|---|---|---|
| `1:1` / `16:9` 等具名比例 | 按所选比例重绘 | 传 `ratio`，`size` 传等效面积边长 |
| **自适应** | 由参考图决定 | 不传 `ratio`，`size` 传等效面积边长 |

**分辨率在两种情况下都生效**：它决定出图面积（自适应时按「等效面积边长」，即 ≈ √出图面积换算）。

供应商侧据此切换主 latent 的来源：不传 `ratio` 时取参考图编码（真正的图生图），传了 `ratio` 才走 `ResolutionSelector` 算出的空 latent（按指定比例、参考这张图重绘）。

## 重写提示词

参数面板底部有「**重写提示词**」开关（适用于工作流带提示词改写分支的供应商，如 `TextGenerate` + `ComfySwitchNode`）：

- **开（默认）**：提示词先交给工作流里的改写模型，用改写后的文本出图。
- **关**：提示词原样送进文本编码节点，跳过改写分支。

平台给图片生成的请求体是严格白名单（只有 `providerId / modelId / prompt / images / ratio / size` 会到达供应商），所以开关状态搭在 `size` 的前缀上：

```
size = "1024"    重写开启（默认）
size = "+1024"   重写关闭
```

前缀不改变数值语义（`Number("+1024") === 1024`），因此不认这个约定的供应商行为完全不变。

## 出图后的玩法

选中节点（且已有出图）后，顶部会出现这些按钮：

| 按钮 | 作用 | 前提 |
|---|---|---|
| **全景图** | 生成 720° 球面（2:1）/ 360° 环绕（4:1）全景，并可在全景球里预览截图 | 需要能吃参考图的模型；全景比例由工作流直传宽高算出 |
| **扩图** | 选方向与幅度向外延伸画面，原图内容作为保留核心 | 需要能吃参考图的模型；目标比例按「原图比例 × 方向 × 幅度」算出 |
| **局部重绘** | 画笔涂抹待改区域，只重绘该区域 | 需要能吃参考图的模型；结果落在新建的 ComfyUI 图片节点里 |
| **动漫转真人** | 一键把二次元角色重绘成写实照片，保留构图与姿势 | 需要能吃参考图的模型；无参数，点按钮直接跑 |
| **放大** | 用放大模型（SeedVR2 等）把当前出图做超分辨率放大 | 需要已安装声明 `upscale` 的模型；倍率取本节点的「放大倍数」，无参数面板 |
| **打光** | 在三维舞台上调主光/轮廓光的方向、强度与色温，重绘一张保留原画面结构的图 | 同上 |
| **多角度** | 绕主体移动机位（水平环绕、俯仰、距离、镜头）后重绘新视角 | 同上 |
| **宫格切分** | 把出图切成 N 宫格并建成一组图片节点 | 纯本地切图，不调模型；需启用内置图片节点插件 |
| **替换图片** | 用本地图片替换节点输出 | 非空、≤ 100 MB 的图片；不删除原文件，复制节点仍可引用 |
| **标记** | 画笔/矩形/文字标注后另存为子节点 | 需启用内置图片节点插件 |

**这些玩法的结果都落在新建的 ComfyUI 图片节点里**：沿用本节点的模型、分辨率与比例，并自动从本节点的图片输出连一条参考图连线过去，生成由新节点自己发起。提示词里的 `{{ref 1}}` 会换成「参考 1」，与引用编号对得上。

**放大**是唯一会换模型的玩法：它优先用本节点当前选中的放大模型，没选就自动找第一个声明了 `upscale` 的（通常是 SeedVR2），一个都没装时按钮禁用并提示去设置里安装。新节点不吃提示词与 LoRA，尺寸和比例也由放大模型按原图推导，所以只带过去「放大倍数」。

**局部重绘**多走一步：编辑器导出涂抹区域的标注图与蒙版，连同原图一起提交给工作流做引导（工作流没有原生 mask 通道，靠「原图 + 红色标注图」告诉模型改哪里）。**成图直接用模型输出的整张**——模型除选区外通常还会做必要的融合修改（色调、光线衔接），按蒙版裁剪会把这些丢掉、边界还会留接缝。出图前新建的重绘节点会直接显示标注图（原图叠红色选区，角标写明「红色标注为重绘区域」），出图后底栏的「查看重绘标注」可以随时回看涂了哪块。

打光、多角度、动漫转真人的比例默认「自适应」（跟随原图），因为这三种玩法都要求出图与原图同比例。面板里可手动改成其它比例。

扩图的目标比例由「原图比例 × 方向 × 幅度」算出，不受上面的默认值影响。

部分玩法会自动带上匹配的推荐 LoRA，新建子节点里已经选好（可在子节点的 LoRA 按钮里改强度或清掉）：

| 玩法 | 自动选择的 LoRA |
|---|---|
| **全景图** | `pano360_qwen21_edit_v1`（720°/360° 等距柱状贴图） |
| **扩图** | `qwen-image-2.1-outpaint-v2`（补全画面外区域） |
| **动漫转真人** | `Qwen2.1_Anything2RealCharacters`（只换渲染方式） |
| **局部重绘** | `qwen-image-2.1-consistency`（压住重绘的整体漂移） |

几个面板的输出设置里都有「**重写提示词**」开关：开启时提示词先交给工作流的改写模型，关闭时原样送进文本编码节点。默认开启，与节点主面板一致。

所有面板互斥（都要占用底栏或全屏），打开一个会自动关掉其余；编辑态没确认前也会先取消。

## 放大模型

选到声明了 `upscale` 的模型（如 **SeedVR2 图像超分**）时，节点界面会简化——超分只放大、不改画面内容，因此：

- **只保留「放大倍数」下拉**（档位由模型的 `upscaleMultipliers` 声明，缺省 1.5× / 2× / 3× / 4×，**默认 2×**）
- 隐藏参数按钮（分辨率 / 比例 / 重写提示词）、LoRA 按钮、提示词输入框
- 顶部九个玩法按钮全部禁用（都依赖提示词通道）
- 接入图片后即可发送，不需要提示词

模型自己按原图尺寸推导输出，节点不传 `size` 与 `ratio`。

## LoRA 堆叠

底栏「比例 · 分辨率」参数按钮**右侧**有一个 **LoRA** 按钮：没启用时显示「LoRA」，启用后显示 `LoRA·N`（N 是启用条数）。点开才展开管理面板——可**添加**（默认 4 行，最多加到 12 行）、**删除**、**调强度**。强度是数字输入框，范围 **-10 ~ 10**、步长 0.05，**缺省 1**（即 100% 效果），**负值表示反转**。按从上到下的顺序依次应用，只列出与当前底模匹配的 LoRA。

列表从本机 ComfyUI 实时读取（`http://127.0.0.1:8188/object_info`），**只显示与当前底模匹配的目录**——LoRA 跨底模使用会直接报错，其余底模的（Krea2 / Z-Image / Flux 等）不会出现在列表里。改了 LoRA 文件后重开节点面板即可刷新。

要求 ComfyUI 已加载「**LoRA 堆叠加载器（仅模型）🐈‍⬛**」这个自定义节点（类名 `🐈‍⬛StackLoras`）。没加载时列表区会说明读不到原因，其余功能不受影响。

Qwen Image 2.1 的**文生图与图生图都支持**——两个工作流里都串了堆叠节点。文生图接在 `#484 → #600 → #496`，图生图接在 `#502 → #600 → #509`，都是 MODEL 直连。切换模型不用重设 LoRA。

## 说明

- 尺寸口径按模型能力区分：能吃参考图的供应商按「等效面积边长」接收 `size`（跟随参考图比例时比例未知，只能用面积表达百万像素），文生图供应商仍按「分辨率 + 比例」推导的长边像素接收。
- 图生图需要供应商工作流本身包含接收图片的节点（如 `LoadImage`），并且该节点参与实际出图链路；若工作流把它接在被旁路的分支上，参考图不会生效。
