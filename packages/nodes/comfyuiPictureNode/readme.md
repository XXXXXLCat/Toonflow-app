# ComfyUI-图片

图片节点与全部图片玩法的合体版：像图片节点一样只做图片的导入与展示，但工具栏自带图片生成节点的那一整套玩法。

## 输入与输出

- 导入本地图片文件，单个文件不能为空且不超过 100 MB。
- 输入端「来源图片」可接上游节点的图片输出；输出端「图片输出」可连接图片生成、视频生成等节点。

## 与其它图片节点的区别

| | 图片节点 | ComfyUI-图片 | ComfyUI-图片生成 |
|---|---|---|---|
| 图片导入 / 替换 / 预览 | 有 | 有 | 有（替换） |
| 全景图 / 局部重绘 / 打光 / 多角度 | 有 | 有 | 有 |
| 制作资产 / 扩图 / 动漫转真人 / 放大 | 无 | 有 | 有 |
| 历史记录 | 无 | 有 | 有 |
| 提示词与生成按钮 | 无 | 无 | 有 |

## 玩法如何出图

本节点**自身不生成图片**。点击任一玩法后，画布会在当前节点右侧**自动新建一个 ComfyUI 图片生成节点**，把这张图作为参考图接进去并开始出图；原图保持不动，历次结果也都留在新节点的历史记录里。

- 打光、多角度、制作资产、扩图：先打开参数面板（面板内可直接选模型、档位与比例），确认后生成。
- 动漫转真人、放大：一键玩法，没有参数面板。动漫转真人第一次使用会让你选一次模型并记住；放大直接取已安装的放大模型（如 SeedVR2），没有则提示先安装。
- 局部重绘：在原图上涂抹选区，出图后按蒙版在本节点内合成。

## 使用方法

1. 点击上传按钮选择图片，或把上游节点的图片接到「来源图片」。
2. 选中节点，使用顶部工具栏的对应玩法按钮。
3. 想直接拿起这张图继续编辑时，也可以用「替换图片」换成本地文件。
