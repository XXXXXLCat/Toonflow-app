# ComfyUI-视频生成

接入本地 ComfyUI 工作流的画布节点，用于生成视频。节点的参数体系沿用平台视频模型的能力声明，因此同一份工作流能按供应商声明的模式支持**文生视频**、**单图参考**、**首尾帧**等用法。

## 输入与输出

- 输入支持文本、图片、视频和音频，实际可用的素材组合取决于所选模型声明的 `mode`。
- 输出生成的视频；播放器可把当前帧、首帧或尾帧截取为图片，输出也可被下游节点引用。

## 用法

1. 确保本地 ComfyUI 已在 `127.0.0.1:8188` 运行，且「设置 → 媒体模型」里已安装 ComfyUI 视频供应商。
2. 在画布「添加节点」中选择「ComfyUI-视频生成」。
3. 填写提示词，选择模型，按需接入参考素材。
4. 打开生成设置，选择模式、时长、分辨率、比例；工作流模型的时长是 **1–15 秒**的整数档位（点选），还会显示**百万像素**、**重写提示词**与 **Turbo**。模型允许时可切换「生成音频」。
5. 点击「生成视频」，需要中止时点击「停止生成」——中止会同时撤销 ComfyUI 上已提交的任务（执行中的中断、排队中的移除），不会让它继续占着显存跑完。

## 参数来源

节点的可选参数**全部来自所选模型的能力声明**，不写死在节点里：

| 参数 | 来源字段 | 行为 |
|---|---|---|
| 生成模式 | `mode` | `text` 文生视频；`singleImage` 单图参考；`startEndRequired` 首尾帧必填；`endFrameOptional` 尾帧可选；`startFrameOptional` 首帧可选；数组形式为混合参考（如 `["imageReference:2"]`）。当前引用只对应一个模式时不显示（下拉仅在有多个可选模式时出现），下拉选项按素材去向显示为首帧 / 尾帧 / 首尾帧 / 参考素材 |
| 时长 | `durationResolutionMap` / 工作流 | 云端模型从档位里选；工作流模型的时长在画布上是 `Float (duration)`，节点提供 **1–15 秒**的整数档位（5 列 × 3 行点选） |
| 分辨率 | `durationResolutionMap` | 选项随所选时长收敛；工作流模型没有档位，该项不显示 |
| 高宽比 | `imageRatios` | 未声明时用节点内置的通用比例；工作流供应商据此把纯 `W:H` 映射成自家枚举 |
| 百万像素 | `imageSizes` | 未声明时用兜底档位 `0.4 / 0.9 / 1.6 / 2` |
| 生成音频 | `audio` | `true` / `false` 时固定不可切换；`"optional"` 时由节点提供开关 |

未声明的能力项不会出现在设置面板里。**模式下拉只在当前素材真的能选到不同结果时才出现**，且只列出当前可用的模式；模式由引用唯一确定（或一个都匹配不上）时，节点改为在提示词下方用一行文字说明。使用首尾帧模式时，图片按引用顺序分配为首帧、尾帧；「首帧可选」模式仅有一张图片时，该图片作为尾帧。同一组素材下结果相同的模式不构成选择——例如两张图时「首尾帧必填」与「首帧可选」都会得到首帧+尾帧，下拉不会出现。

下拉里的选项**写的是素材的去向（首帧 / 尾帧 / 首尾帧 / 参考素材），不是模式声明名**——「单图参考」「首帧可选」这类名字说的是"哪一端可选"，读的人还得自己反推图片去哪；写结果更直接。一个模式的结果会随素材数量变化（「首帧可选」在 1 图时是尾帧、2 图时是首尾帧），因此标签由节点按当前素材数计算。模式下拉可见时，选项本身已经说明了去向，提示词下方那行首尾帧说明就不再重复出现。

以「MiniMax H3 图生视频」为例，**接入一张图片时会看到「生成模式」下拉**，选项就是**「首帧」与「尾帧」**：选首帧即由该图往后推演，选尾帧则由工作流自行推演开头（即画布上的 L2VA 用法，对应 `startFrameOptional`）。两张图时两种选择结果相同，因此下拉自动隐藏。

图片、视频、音频三类素材**只有混合参考模式能同时接收**。命中混合参考时，设置面板不显示模式下拉（当前引用只对应这一种模式），节点改为在提示词下方说明素材的去向与上限（上限取自模型声明的能力项，如「最多 图片 9 个、视频 3 个、音频 3 个」）。这类模式下素材只作为参考输入参与生成，没有首帧/尾帧语义，因此也不会出现首尾帧的分配说明。

若当前素材组合**一个模式都匹配不上**（多见于类型或数量超出模型声明，如参考素材超过上限），下拉同样不出现——它此时没有可选项、选了也过不了校验；节点改为在该位置列出模型支持的能力（如「文生视频、混合参考（最多 图片 9 个、视频 3 个、音频 3 个）」），生成仍会被拦截并提示调整引用或更换模型。

模型声明了 `text` 模式时，**不接入任何素材即以文生视频提交**：请求不携带参考素材，工作流按无输入分支执行，高宽比、百万像素、时长等参数照常生效（节点会在提示词下方给出说明）。

## 工作流模型与输出规格通道

本地工作流没有「分辨率档位」的概念，所以当模型**未声明 `durationResolutionMap`**（或**声明了 `imageSizes`**）时，节点按工作流模型处理：

- 设置面板隐藏分辨率下拉，**时长**改为 1–15 秒的整数档位（5 列 × 3 行点选），并出现**百万像素**、**重写提示词**、**Turbo** 三组参数。
- 平台给视频请求的字段是严格白名单（没有图片请求那样的 `size` 通道），因此这三个参数由节点编码进 `resolution`，格式为 `mp=<百万像素>|rw=<0/1>|tb=<0/1>`；不含 `=` 的片段视为真实分辨率字符串，两种写法可共存。
- **时长**不占用这套编码，直接走请求里已有的 `duration` 字段；供应商把它写进画布上的 `Float (duration)`，节点提供 1–15 秒的整数档位，帧数换算交给工作流处理。
- 供应商解析该字段：`mp` 驱动分辨率节点、`rw` 决定是否走提示词改写分支、`tb` 决定采样步数分支。不认识该约定的供应商不会收到这套编码（它们的模型声明了分辨率档位，走原来的真实分辨率）。

## 与「视频生成」节点的关系

本节点与内置「视频生成」节点使用同一套请求体与参数体系，区别在于：

- 本节点面向**本地 ComfyUI 工作流供应商**（默认优先选择 `comfyuiVideo` 供应商）。
- 内置「视频生成」面向云端媒体供应商。

因此供应商只要按平台规范导出工作流，两个节点都能驱动它。

## LoRA 堆叠

底栏参数按钮**右侧**有一个 **LoRA** 按钮：没启用时显示「LoRA」，启用后显示 `LoRA·N`。点开可**添加**（默认 4 行，最多 12 行）、**删除**、**调强度**（范围 -10 ~ 10、步长 0.05、缺省 1、负值表示反转）。

列表从本机 ComfyUI 实时读取，只显示 `MiniMax-H3` 目录下的 LoRA（电影感、真实人物、战斗、运镜、空间物理等）——目录名即底模归属，跨底模混用会让 ComfyUI 直接报错。

工作流里已串好「🐈‍⬛StackLoras」（在底模加载器与采样之间），未指定的槽位自动跳过。需要 ComfyUI 已加载该自定义节点，没加载时列表区会说明原因。

## 说明

- 参考素材按端口接入顺序参与生成。
- 比例与百万像素的具体取值范围由供应商工作流决定，节点负责按声明展示、按约定传递。
- 云端模型的时长与分辨率选项完全由供应商的 `durationResolutionMap` 决定；工作流模型没有档位，时长固定为 **1–15 秒**的整数档位，分辨率不显示。
- 工作流的时长会先换算成帧数再对齐到 `frames ≡ 5 (mod 17)`（fps 24），因此**实际输出时长与输入会有小幅差异**：1 秒 → 1.63 秒、3 秒 → 3.04 秒、6 秒 → 6.58 秒、15 秒 → 15.08 秒。
